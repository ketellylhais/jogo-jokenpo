# Jogo Jokenpo

Um jogo simples de pedra, papel e tesoura (Jokenpo) desenvolvido em JavaScript para praticar lógica de programação e manipulação do DOM.

## Como jogar

1. O jogador escolhe entre pedra, papel ou tesoura.  

2. O computador faz sua escolha aleatória.  

3. O resultado é exibido na tela informando quem ganhou.

## Tecnologias usadas

- JavaScript  

- HTML  

- CSS
